# work-schedule-poll

Страница опроса графика работы для сотрудников: три варианта (9:00–18:00, 8:30–17:30, 8:00–17:00, обед 1 час, пятидневная неделя), выбор города, живой сезонный фон.

## Важно

Эта копия статическая. Сам опрос (хранение голосов, проценты, список проголосовавших) работает только на опубликованной странице в Claude, потому что хранилище голосов предоставляет Claude. На GitHub Pages видно только оформление.

## Публикация на GitHub Pages

1. Создайте репозиторий `work-schedule-poll` и загрузите в него `index.html` и этот файл.
2. Откройте Settings → Pages.
3. В разделе Source выберите ветку `main` и папку `/ (root)`, нажмите Save.
4. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/work-schedule-poll/`.
